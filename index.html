The white boxes on screen are a preview (the red outline is not exported). Export flattens every page to a single picture with those areas painted solid white, then builds a fresh PDF. The exported file has no text, layers, fonts or metadata to peel back, so the covered content cannot be recovered with a PDF editor or image editor. Your original file is never changed.

Nothing is uploaded. The PDF never leaves this tab. The only network requests are for the page's font and, if the bundled copies in the vendor folder are missing, the two open-source libraries it uses (pdf.js and pdf-lib).
